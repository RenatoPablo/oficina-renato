# Oficina Renato

Sistema web desenvolvido para gerenciamento de uma oficina mecânica.

O projeto permite controlar clientes, veículos, ordens de serviço, serviços realizados, peças e estoque em um único sistema.

---

## Funcionalidades

- Cadastro e gerenciamento de clientes
- Cadastro de veículos
- Associação de veículos aos proprietários
- Criação e gerenciamento de ordens de serviço
- Adição de serviços e peças nas ordens
- Controle de estoque
- Controle de usuários
- Finalização de ordens de serviço
- Impressão de ordens de serviço
- Dashboard com informações importantes
- Avisos de estoque baixo
- Controle de ordens abertas e atrasadas

---

## Tecnologias

O projeto foi desenvolvido utilizando:

- PHP
- Laravel 11
- MySQL
- Blade
- Bootstrap
- JavaScript
- Vite
